# Piano Practice

A standalone web app for studying piano pieces from MIDI files: it engraves the
music on a grand staff, plays it back with a sampled grand piano, and lets you
practice along on a MIDI keyboard with real-time visual feedback.

![screenshot](docs/screenshot.png)

## Features

- **Open any MIDI file** (`.mid`) — or press **Demo** for the bundled Minuet in G.
- **Staff notation** rendered as one long scrolling grand staff (treble + bass):
  key signature (from the file, or auto-detected from the pitches), time
  signature, barlines with measure numbers, accidentals with proper
  measure-carry rules, stems, flags, dots and ledger lines. Engraved with the
  professional [Bravura](https://github.com/steinbergmedia/bravura) font.
- **Listening mode** — plays the piece at its natural tempo (the MIDI tempo
  map, including mid-piece tempo changes, is the 100% baseline). A cursor
  follows the music in real time, the score auto-scrolls, and currently
  sounding notes light up blue.
- **Practice mode** — the piece plays exactly as in listening mode while your
  MIDI keyboard is monitored. Notes you play in time turn **green**; notes you
  miss (or play too late) turn **red** and the music keeps going. A running
  ✓/✗ counter tracks the session. Configurable timing window
  (±200/350/600 ms) and optional guide audio.
- **Transport** — play/pause, restart, ±5 s skip, and click anywhere on the
  score to jump there.
- **Tempo control** (25%–150%) — change speed at any time, even during
  playback; start slow and work up. The timing window adapts so judging feels
  the same at every speed.
- **Sampled grand piano** — the Salamander Grand Piano (Yamaha C5, recorded by
  Alexander Holm), sampled every minor third across the full range and bundled
  with the app, so everything works offline.

## Running it

Requires [Node.js](https://nodejs.org) and a **Chromium-based browser**
(Chrome, Edge, Brave …) — Web MIDI, needed for practice mode, is not reliably
available in Firefox or Safari.

```bash
npm install
npm run dev        # then open the printed http://localhost:5173 URL
```

For a static build you can host anywhere (or open via any local file server):

```bash
npm run build      # output in dist/
npm run preview    # serve the build locally
```

## Using practice mode

1. Connect your MIDI keyboard/controller and switch to **Practice**.
2. The browser will ask for MIDI permission the first time; your device then
   appears in the **MIDI input** selector (auto-selected if it's the only one).
3. Press play and follow the cursor. Pick a slower tempo first; raise it as
   the piece settles in.

No MIDI keyboard at hand? You can simulate input from the browser console:
`__piano.noteOn(60)` plays middle C into the practice engine.

## How it works (short tour)

| Module | Role |
| --- | --- |
| `src/score.ts` | Parses MIDI (via `@tonejs/midi`) into a score model: staff split per hand, key detection, pitch spelling, accidentals, measures |
| `src/renderer.ts` | SVG engraving of the grand staff + cursor, using SMuFL glyphs from Bravura |
| `src/sampler.ts` | Web Audio piano: Salamander samples, pitch-shifted between sample points, with release envelopes and a compressor |
| `src/player.ts` | Transport & lookahead scheduler; positions are in "score seconds" so the user tempo factor is a pure wall-clock mapping |
| `src/practice.ts` | Matches incoming note-ons against the score within the timing window; marks hits/misses |
| `src/midiInput.ts` | Web MIDI device discovery and note-on events |

The demo file is generated by `npm run make-demo`
(`scripts/make-demo.mjs` → `public/demo/minuet-in-g.mid`).

## Roadmap (v2 ideas)

- Edit mode: correct/transpose notes and save the modified MIDI.
- Optional audio-file backing track (play the original recording in sync with
  the score instead of the sampled piano).
- Beaming for eighth/sixteenth groups; paginated sheet layout.
- Per-hand practice (mute/judge left or right hand only).
