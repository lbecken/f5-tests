Riverside Medical Center EMR

This is the server half of the FHIR playground. Useful endpoints (all relative to this context path):

  • fhir/metadata — the CapabilityStatement (what this server can do)
  • fhir/Patient — search all patients
  • fhir/Patient?family=diaz — search by family name
  • fhir/Encounter?status=in-progress — current inpatient census
  • fhir/Observation?patient=1 — results for a patient
  • GET messages/next — pop the next outbound FHIR message Bundle
  • messages/pending — queued message count
  • POST simulate/admit | discharge | lab — generate clinical activity

The friendly way to consume all of this is the ward-dashboard webapp.
